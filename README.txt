MOMENTUM — Habit Tracker

Files:
- index.html: the app
- manifest.json: installable app metadata
- sw.js: offline cache

IMPORTANT:
To install as a home-screen app on Android, the files must be hosted on an HTTPS website.
1. Upload the contents of this folder to an HTTPS static host.
2. Open the hosted index.html in Chrome on Android.
3. Tap Chrome's menu (⋮) > Install app or Add to Home screen.
4. Your habits and saved days are stored locally in that browser on that device.

The app includes editable/addable/removable habits, daily check-offs, daily saving, weekly/monthly averages and comparisons, streaks, history, and JSON backup/restore.
